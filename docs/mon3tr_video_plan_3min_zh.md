# Mon3tr 模组：3 分钟宣传与解说视频方案

策划日期：2026-10-13。玩法依据为当前本地 Mon3tr 与源枢源码，以及项目工坊中文说明；Mon3tr 当前版本标记为 v1.0.2。本方案提供分镜、口播与录制安排，尚未录制游戏素材。

## 影片定位

**主题：毁灭，同时治愈。**

做一支约 3 分钟、16:9 横屏的宣传兼玩法解说视频。面向饥荒玩家与明日方舟玩家，先展示角色的两种魅力，再用真实战斗画面讲清玩法。看完后，观众应记住三个特点：攻击可以治疗队伍；治疗可以补给装备；熔毁可以跃入敌群，用持续进攻维持生命。

情绪从开场的冲击，进入清楚、轻快的讲解，再在熔毁与团队实战中推到高潮。Mon3tr 按独立可玩角色介绍。

推荐标题：**《毁灭，同时治愈｜饥荒联机版 Mon3tr 模组介绍》**。

备选标题：**《攻击也能治疗队友？Mon3tr 来到饥荒联机版》**。

封面构图：角色立绘占一侧，另一侧放熔毁形态实机截图；治疗链作为连接两侧的视觉元素。大字“毁灭，同时治愈”，小字“Mon3tr × 饥荒联机版”。不要在封面塞入完整技能说明。

## 可直接录制的口播稿

每段之间允许停顿。以正常、清楚的语速录制，熔毁段留足时间给画面解释；整合实战的末尾留给原声。

**0:00–0:10**

> 一边撕开敌阵，一边治愈同伴。Mon3tr，来到永恒领域。

**0:10–0:24**

> 这次带来的，是饥荒联机版角色模组 Mon3tr。手持重构体，以真实伤害迎敌，再把攻击、治疗和装备充能，连成一套战斗循环。

**0:24–0:50**

> 攻击命中会积攒技力。初始技能“超压链接”，在技力充足后，随下一次攻击自动发动弹射治疗，优先照顾生命比例较低的自己和友军，再向其他目标跳跃。持续参与战斗，就能帮队伍把血线拉回来。

**0:50–1:15**

> 精英一后，还可以开启“超负荷”。技能期间，每次命中都能触发弹射治疗，并通过强化的战术协同，为被治疗者提高攻速。它还可以与超压链接叠加，让 Mon3tr 在持续交战中，同时承担输出与支援。

**1:15–1:39**

> 重构体的充能越高，攻击就越强。保持饱食并装备它，可以先缓慢充到八成；之后，弹射治疗还能继续补充。即使生命已满，治疗也能为重构体充能，为源枢的 M3茧甲恢复耐久。

**1:39–1:52**

> 战斗积累经验，当前阶段满级后，再通过精英化解锁新能力。精英一开放超负荷与战术协同；精英二，解锁熔毁。

**1:52–2:31**

> 需要突破时，就发动“熔毁”。跃向选定位置，卸下手持装备，切换形态，以爪击造成范围真实伤害。生命上限、攻击、攻速和攻击范围都会强化；重构体还能贡献部分充能，进一步增强这次突击。但生命也会持续流失，需要靠命中回血维持。技能结束或濒死时，返回出发位置附近，再及时补给。

**2:31–2:50**

> 先用超负荷维持队伍，再以熔毁切入敌阵。范围攻击与弹射治疗同时展开，让队友跟上这次突破。毁灭，同时治愈——这就是 Mon3tr 的战斗方式。

**2:50–3:00**

> 想让 Mon3tr 加入你的冒险？下载入口见简介，记得同时启用前置模组“源枢”。

## 录制安排与素材清单

建议先集中录玩法素材，再录立绘、UI 和收尾。录制准备使用一个能正常展示技能的存档，至少安排一名队友；需要更明显的多人弹射画面时，增加第二名队友。

录制素材需覆盖初始、精英一、精英二三个阶段。可以使用不同存档或同一角色成长过程。展示时给出对应阶段字幕，让观众理解技能的解锁顺序。

| 素材编号 | 必录内容 | 拍到什么才够用 | 对应成片 |
| --- | --- | --- | --- |
| A | 角色登场 | 选择界面、持剑走动、攻击动作、立绘 | 开场与定位 |
| B | 超压链接完整触发 | 受伤友军与 Mon3tr 在治疗可达范围内；同屏看到攻击、技力、治疗链与回血 | 0:24–0:50 |
| C | 超负荷持续治疗 | 开启技能后连续命中；治疗链多次出现；战术协同图标或说明 | 0:50–1:15 |
| D | 重构体饥饿充能 | 手持武器、饥饿大于 40、充能从门槛附近升到 80%；长等待部分用加速或跳切 | 1:15–1:39 |
| E | 满血继续充剑 | 重构体已有至少 80% 充能；满血 HUD 清楚可见；弹射治疗后充能继续增长 | 1:15–1:39 |
| F | 茧甲获得补给 | 穿着茧甲的目标接受弹射治疗，耐久上升；让事件与变化发生在同一短镜头里 | 1:15–1:39 |
| G | 精英化成长 | 经验、阶段满级、配方、解锁图标各一个短镜头 | 1:39–1:52 |
| H | 熔毁突击 | 选择落点、跃击、落地、爪击多个敌人，保留启动语音 | 开场与 1:52–2:31 |
| I | 熔毁的生命变化 | 一段暂停攻击的生命流失，一段重新攻击的命中回血；避免其他回血来源干扰 | 1:52–2:31 |
| J | 熔毁返回 | 保留出发信标，录到结束或濒死后的返回过程以及剩余血量 | 1:52–2:31 |
| K | 组合实战 | 开启超负荷后发动熔毁；范围攻击、治疗链与队友进攻在同一段画面出现 | 2:31–2:50 |
| L | 下载与署名卡 | 标题、前置提示、简介入口、现有创作署名 | 2:50–3:00 |

**优先录 B、C、E、H、I、J、K。** 这些是整支视频最能证明玩法特色的画面。每个关键动作前后多保留 3–5 秒，方便调整剪辑点。

录制技巧：

- 战斗主画面保留生命、技能状态等相关 HUD。需要展示队友生命时，可补录队友视角，再在剪辑中作为小窗放到同一时刻；治疗链的第一次展示仍应保留清楚的同屏动作。
- 展示治疗时让友军在可达范围内，避免走散。满血充剑镜头减少附近其他低血友军，便于让治疗链确实选中展示目标。
- 饥饿充能过程较慢，优先拍接近 80% 的阶段，再跳切到治疗继续充能；给长过程标注“加速”或“时间跳切”。不要用快切暗示武器能瞬间由低充能充满。
- 满血充剑镜头可先卸下茧甲，以免茧甲自身的生命与耐久交换干扰血量证明；随后单独拍茧甲受到弹射治疗的瞬间。
- 熔毁录制保留完整素材，成片再跳切至返回。剪辑时标注“技能结束”，让观众理解中间有时间经过。无需把实际技能持续时间全部放进视频。
- 若技能讲解使用多人同一场景，整合实战沿用这支队伍，可以让前后画面更连贯。

## 字幕、音乐与声音

字幕分为底部口播字幕和角落机制提示。技能名固定位置出现；重要提示一次只放一条，控制在一至两行。例如“攻击积攒技力”“满血也能充能”“命中回血维持生命”。

开场用治疗特效声与熔毁撞击声形成节拍。解说段音乐压低，熔毁段逐步抬高；2:31 后进入最强的一段，并在最后几秒给战斗原声留出空间。可以采用一首有渐强结构、适合使用的视频音乐，不必逐技能换曲。

超负荷和熔毁都有已绑定的角色语音。让其中一次启动语音完整响起，旁白稍后接入；随机播放到什么台词，就配对应字幕。现有熔毁语音字幕包含“正在切换形态。”“毁灭，同时治愈。”“接敌，速战速决。”，可以从录到的素材中选择适合开场或高潮的一条。

三围如果需要展示，只在登场时放一张短信息卡：生命 150／饥饿 150／理智 200，初始物品：重构体。完整配方、每跳衰减、详细倍率和装备其他属性留在工坊介绍中。

结尾下载卡保留当前署名信息，可使用小字：**画师：Jack Day、GPT-Image-2.5；代码：望月心灵、GPT-6.1 Sol。** 说明栏放工坊入口、前置、反馈入口与完整署名。

## 文案与画面核对要点

这些边界用于制作人员核对，不必全部放进口播。

| 内容 | 成片应表达的意思 |
| --- | --- |
| 技能获得 | 开局拥有超压链接；精英一解锁超负荷与战术协同；精英二解锁熔毁。 |
| 治疗触发 | 超压链接在技力足够后的攻击命中时触发；超负荷是开启后每次命中触发。 |
| 治疗目标 | 优先考虑生命比例较低的目标；治疗有范围与跳跃次数限制，因此“全队无限回血”不适合作为宣传措辞。 |
| 叠加关系 | 超压链接可与超负荷叠加；熔毁期间也可继续使用这两种治疗机制。 |
| 熔毁回血 | 熔毁自身的命中回血作用于 Mon3tr；组合实战中的友军治疗来自超压链接或活跃的超负荷。 |
| 饥饿充能 | 重构体必须手持装备，饥饿大于 40 时缓慢消耗饥饿充到 80%。 |
| 治疗充能 | 重构体至少达到 80% 后才接受 Mon3tr 弹射治疗继续充能；普通回血道具不等于这一充能来源。 |
| 满血补给 | 满血目标仍可接受治疗链的装备补给，但要确实被治疗链选中。 |
| 装备归属 | 重构体来自 Mon3tr 模组；M3茧甲属于前置源枢，介绍为装备联动。 |
| 熔毁代价 | 强化形态会持续流失生命，命中回血用于维持；技能期间解除并限制手持装备，骑乘时无法使用。可将骑乘限制放在小字幕中。 |
| 熔毁退场 | 技能结束或濒死后返回出发位置附近，有短暂保命缓冲；返回后仍需留意生命。措辞使用“返回”，避免表达为全程无敌或死亡复活。 |
| 技能时长 | 方案不写死持续秒数，以实际录制版本呈现；返回镜头允许明确时间跳切。 |
